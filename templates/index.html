About the platform

One platform, every step of the quiz.

QuizNest was designed as a college mini-project to demonstrate a complete, working web application — from a secure registration flow to real-time, timed multiple-choice testing. Educators can publish quizzes in minutes; students get a distraction-free interface and instant feedback the moment they submit an answer.

  • No installation — works on any browser
  • Responsive layout for phones, tablets & desktops
  • Built with Flask, Bootstrap & vanilla JavaScript
